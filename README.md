GLOWMOTH — keep the last light alive. A one-screen neon night-garden arcade game: steer a glowing moth with the mouse or arrow keys/WASD, gather glowing pollen to build a combo up to ×8, dodge the bats — three hits and the light goes out. Survive three 45-second nights to win. Plain HTML5 canvas and JavaScript: no build step, no external assets, no network requests, all sound synthesized in WebAudio.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
